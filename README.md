# denkschuldt.github.io

A quiet, cinematic creative studio built as an interactive WebGL experience.

See [docs/CAMERA_SYSTEM.md](docs/CAMERA_SYSTEM.md) for cinematic camera targets, transitions, responsive framing, and reduced-motion behavior.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: production build (navigation package + vinext)
- `npm test`: build, check performance budget, and run all tests
- `npm run lint`: run ESLint
- `npm run format`: format with Prettier
- `npm run typecheck`: run TypeScript type checking
- `npm run quality`: format check + lint + typecheck

# I write poems

I write poems to sometimes stay,
and others because I just want to run away.
I write them to mentally touch grass and feel,
to take shelter in myself whenever I have the need.

I write poems because I’ve lived so many lives,
some of them evolved and others have naturally died.
There were lives that didn’t last long,
but that I can replay in my head like my favorite song.

I write poems for the lives I have yet to live,
dreaming through words, futures to be seen.
I write them because it feels so good,
to be able to create verses even when I’m not in the mood.

I write poems, sometimes just verses.
I write my feelings across universes.
